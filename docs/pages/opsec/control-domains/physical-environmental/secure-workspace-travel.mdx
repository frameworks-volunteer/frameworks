# Secure workspace & travel

Travel and non-primary work locations increase both physical and digital exposure.

## Pre-travel

1. Assess destination risk (crime, legal, surveillance, political conditions).
2. Use dedicated travel devices with minimal data when feasible.
3. Patch devices, verify backups, and test secure communications before departure.
4. Prepare emergency contacts and escalation procedures.

## In transit and on location

1. Keep devices in physical control; avoid unattended exposure.
2. Use privacy screens and avoid discussing sensitive matters in public.
3. Prefer trusted connectivity; treat hotel/public networks as hostile.
4. Use secure charging practices and avoid unknown USB sources.

## Post-travel

1. Inspect devices for tampering.
2. Rotate sensitive credentials used during travel.
3. Run security checks before reconnecting to sensitive environments.
4. Report anomalies and feed lessons into future travel playbooks.
